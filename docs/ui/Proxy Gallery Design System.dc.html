Design system · v1

A light, client-rendered vocabulary for the image proxy

Restraint is the brief. JavaScript fetches JSON and builds the DOM; the URL is kept in step with history.pushState, so every state stays linkable. Components extend the custom properties already in static/css/app.css rather than replacing them.

05 — Grid & loading

repeat(auto-fill, minmax(160px, 1fr)). Two loading states that must not be conflated: the page fetch dims the grid it already has, and each tile holds a fixed aspect-ratio placeholder that fades to the image.

The previous grid stays on screen at 45% with pointer events off — dimmed, never blanked, so there is no empty frame between pages. The client knows when a fetch is in flight, so this covers filter and page changes, not only first load.

Reserved space

Explicit width/height on every <img>; loading="lazy" below the fold.

Fade-in

160ms opacity per tile on load. 1 MB at 50 images makes per-tile placeholders worth keeping.

50 on mobile

Minimum tile falls to 110px under 480px wide — dimensions matter more than column count.

06 — Pagination

Absent, not disabled — JS renders no element at all on page 1, so tests assert presence rather than an ARIA state. Real <a href> elements, intercepted on click, so middle-click and copy-link keep working.

Every link carries the current filters, so paging never resets size, grayscale, blur, or count. A click is a pushState; Back and forward are a re-render, never a fetch-and-push.

10 — State & modules

One direction of flow. State is flat and serialisable — it is the query parameters.

URL → state.read() → api.fetchImages() → render() → DOM → event → state.write()
{ page: 1, size: "medium", grayscale: false, blur: 0, count: 10 }
Defaults are omitted

?size=large, not every parameter spelled out. A shared URL stays readable.

Push on intent only

A control change pushes; a response never does. Corrections use replaceState.

One request in flight

Each fetch aborts the last, so fast filter changes cannot land out of order.

Blur debounces at 180ms

The readout paints on every input; the request waits. One fetch per drag, not eleven.

11 — Rules

The URL is the state

Every view is linkable; every change writes to the URL. Nothing is reachable only by clicking.

Hooks are data-testid

Tests never reach for a styling class. Add a testid to anything a scenario needs to find.

One accent, used sparingly

Accent means "non-default value" or "focus". Neutrals carry everything else.

Out of scope

Lightboxes, infinite scroll, client-side filtering, theming controls, dark mode, animation beyond the fade and the loading dim.
